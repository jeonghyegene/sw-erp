# 성원애드피아 ERP — 인사·근태 메뉴 접근 권한 매트릭스

- 작성일: 2026-08-20
- 대상: `인사` 18개 화면 · `근태` 9개 화면 (총 27개)
- 기준: 신규 ERP(`10.6.20.193:3000`) 실제 메뉴 + 각 화면 구현의 권한 분기 + 통합정책서 v2.0
- 메뉴 대조: 2026-08-21 `hr-admin` 계정으로 신규 ERP 메뉴 확인 완료
- 상태: **초안(검토 필요)** — 확정 후 정책 위키에 반영

---

## 1. 역할 정의

| 역할 | 코드 | 설명 |
| --- | --- | --- |
| 인사담당자(관리자) | `hr_admin` | 인사팀. 전사 인사·근태·급여 데이터의 등록·수정·확정 권한 |
| 임원 | `exec` | 임원실. **인사담당자와 동일한 범위**로 접근한다 |
| 부서장 | `manager` | 소속 부서 구성원에 한해 조회·편성·승인 |
| 일반사원 | `employee` | 본인 데이터 조회. 신청·작성은 본인 건에 한함 |

- 부서장의 「소속 부서」 범위는 **본부장인 경우 산하 팀 전체**, 팀장인 경우 본인 팀으로 한다.

## 2. 범례

각 칸은 **메뉴 접근 가능 여부와 조회 가능한 데이터 범위**를 뜻한다.

| 표기 | 의미 |
| :--: | --- |
| O (전사) | 메뉴 접근 가능 · 전 직원의 데이터 조회 |
| O (부서) | 메뉴 접근 가능 · 소속 부서 구성원의 데이터만 조회 |
| O (본인) | 메뉴 접근 가능 · 본인 데이터만 조회 |
| ✕ | 메뉴 접근 불가 |
| 없음 | 권한 부여 대상이 아닌 메뉴 |
