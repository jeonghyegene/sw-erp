# 성원애드피아 ERP 급여 정책 논의 안건

> **작성일:** 2026-08-06
> **대상 문서:** 성원애드피아 ERP 인사·근태·급여 통합정책서 v1.5
> **목적:** 정책서에 규정이 없어서 급여 금액이 확정되지 않는 항목을 순서대로 논의하고 확정한다.
> **결과 반영:** 확정된 내용은 정책서 v1.6에 반영한다.

---

## 이 문서를 보는 방법

각 안건은 아래 4가지로 구성됩니다.

| 구성 | 뜻 |
|---|---|
| **한 줄 요약** | 무엇이 문제인지 |
| **지금 상태** | 정책서와 시스템에 뭐가 있고 뭐가 없는지 |
| **결정할 것** | 회의에서 답을 정해야 하는 질문들 |
| **확정되면 달라지는 것** | 이 결정이 어디까지 영향을 주는지 |

---

## 왜 이 순서인가

앞 안건을 정하지 않으면 뒤 안건을 정할 수 없는 관계가 있습니다.

```
[1] 주휴수당
      ↓  주휴를 확정해야 "통상시급"이 확정됨
[2] 생산직 야간수당 비과세
      ↓  통상시급이 있어야 야간수당 금액이 나오고, 그 금액에 비과세를 적용
[3] 최저임금 검증
      ↓  통상시급이 있어야 최저임금 미달 여부를 계산할 수 있음
[4] 산재 병가 처리
      ↓  산재를 결근으로 볼지에 따라 연차·주휴가 달라짐 → [1]과 연결
[5] 주 52시간 초과분 → 상여금2
      ↓  연장수당 계산이 정리된 뒤에 다뤄야 이중 지급을 막을 수 있음
[6] 식권(바우처)
      ↓  급여에서 차감하는 구조라 공제 항목 정리와 함께
[7] 외국인 근로자      ← 독립 안건 (채용 계획 확인이 먼저)
[8] 증명서 발급        ← 독립 안건 (언제든 가능)
```

**핵심:** 1번 → 2번 → 3번은 반드시 이 순서로. 순서를 바꾸면 다시 계산해야 합니다.

| 순서 | 안건 | 시급도 | 성격 |
|---|---|:---:|---|
| 1 | 주휴수당 | 높음 | 다른 모든 수당의 기준이 됨 |
| 2 | 생산직 야간·연장·휴일수당 비과세 | 높음 | 세금이 매달 틀어짐 |
| 3 | 최저임금 검증 | 높음 | 법 위반 방지 |
| 4 | 산재 병가 처리 | 높음 | 연차·주휴·퇴직금에 연쇄 영향 |
| 5 | 주 52시간 초과분 상여금2 | 중간 | 목적 확정이 먼저 |
| 6 | 식권(바우처) | 중간 | 정책서와 화면이 서로 다름 |
| 7 | 외국인 근로자 | 낮음 | 채용 계획 있을 때 |
| 8 | 증명서 발급 | 낮음 | 독립 |

---

## 먼저, 이미 확정된 사항

### 수습기간 임금 — 100% 지급 (확정)

수습기간에도 임금을 깎지 않고 정식 임금과 똑같이 100% 지급합니다.
법에는 "수습 3개월 동안 최저임금의 90%까지 깎을 수 있다"는 예외가 있지만, **우리는 이 예외를 쓰지 않습니다.**

정책서에 넣을 문장:
> 수습기간 중 임금은 감액하지 않고 정식 임금과 동일하게 100% 지급한다. (최저임금법 §5③ 수습 감액 특례를 적용하지 않는다.)

**좋은 점** — 3번 안건(최저임금 검증)에서 "수습이냐 아니냐"를 따로 볼 필요가 없어져서 계산이 단순해집니다.

**다만 아래 3가지는 추가 확인이 필요합니다.** (금액이 아니라 "처리 방식" 문제)

- [ ] **수습 계약도 고정OT·포괄임금을 적용하나요?** 수습 계약은 기간제로 체결되는데, 임금계약도 별도로 체결하는지
- [ ] **정규직 전환 시 연봉이 오르나요?** 오른다면 전환일부터 새 임금계약을 쓰고, 소급분이 생기는지
- [ ] **수습 미전환으로 나갈 때 `계약 만료`인가요, `중도 퇴사`인가요?** 이 구분에 따라 급여 일할계산 방식과 4대보험 상실 사유가 달라집니다

# 안건 1. 주휴수당

## 한 줄 요약

주 5일 일하고 주말에 쉬어도 하루치 임금(주휴수당)을 줘야 하는데, **일용직만 규정이 있고 정규직·계약직은 규정이 없습니다.**

## 지금 상태

| | 내용 |
|---|---|
| **일용직** | 규정 있음 — 시급의 20%, 조건 3개(주 15시간 이상 / 약정한 주 근무일 다 채움 / 결근 없음), 원 단위 절사 |
| **정규직·계약직** | **규정 없음** |
| **시스템 현황** | 일용직 계약서에 "계약 시급 = 기본시급 + 주휴 20%"로 **합쳐서** 저장하는 구조 |

**왜 문제인가**

1. 정규직 월급에 주휴가 포함되어 있다는 근거 문장이 없습니다. 이게 없으면 "월급 따로, 주휴 따로 달라"는 요구를 막을 근거가 없습니다.
2. 정규직 주휴를 확정하면 **한 달에 몇 시간을 일한 것으로 볼지(월 소정근로시간)** 가 정해집니다. 이 숫자로 **통상시급**을 나눠서 구하는데, 통상시급은 연장·야간·휴일수당 **전부의 기준**입니다. 즉 이 숫자가 틀리면 모든 수당이 틀립니다.
3. 일용직은 시급에 주휴를 합쳐놨기 때문에, **조건을 못 채운 사람에게도 주휴가 지급됩니다.** (주 10시간만 일한 사람, 결근한 사람도 받게 됨)

## 결정할 것

- [ ] **정규직·계약직 월급에 주휴수당이 포함되어 있다**고 정책서에 명시할까요? (일반적으로 그렇습니다)
- [ ] **월 소정근로시간을 몇 시간으로 확정**할까요? 주 40시간 + 주휴 8시간 기준이면 **209시간**입니다. 현재 시스템은 26일 × 8시간 = 208시간으로 계산하고 있어 서로 다릅니다
- [ ] **일용직 주휴를 시급에 합칠까요, 따로 뗄까요?**
  - 합치면(현재) → 계산은 간단하지만 조건 검증이 안 됨
  - 떼면 → 조건 3개를 검증해서 지급/미지급 판단 가능. **권장**
- [ ] 주휴 조건 중 "결근 없음"을 볼 때, **산재·유급휴가·무급휴가는 결근으로 볼까요?** (→ 4번 안건과 연결)
- [ ] **주중에 입사하거나 퇴사한 주**의 주휴는 어떻게 처리할까요?

## 확정되면 달라지는 것

- 통상시급 → **연장·야간·야간연장·휴일수당 전부**
- 일용직 급여대장의 주휴수당 항목
- 최저임금 검증 기준 (주휴 포함 시급으로 볼지)
- 고정OT·포괄임금 계약의 수당 환산

# 안건 2. 생산직 야간·연장·휴일수당 비과세

## 한 줄 요약

**생산직 중 월급이 일정 수준 이하인 사람은 야간·연장·휴일수당에 세금을 안 내도 됩니다.** 연 240만원까지. 우리는 주야 2교대라 해당자가 많을 텐데 정책서에 없습니다.

## 지금 상태

| | 내용 |
|---|---|
| **제도** | 소득세법 시행령 §17 |
| **조건** | ① 생산직 근로자 ② 월정액급여 210만원 이하 ③ 작년 총급여 3,000만원 이하 — **3개 모두 충족** |
| **한도** | **연 240만원**까지 비과세 (일용직은 한도 없이 전액 비과세) |
| **정책서** | 언급 전혀 없음 |
| **시스템** | 지급항목에 "비과세 여부·비과세 한도" 칸은 있지만, 생산직 특례 개념은 없음 |

**월정액급여란?**
매달 고정으로 받는 돈만 말합니다. 기본급 + 고정수당(식대·직무수당 등)은 포함하고, **매달 달라지는 초과근무수당과 상여금은 제외**합니다. 그래서 야간수당을 많이 받아도 월정액급여 자체는 안 올라갑니다.

**왜 중요한가**
야간수당만으로도 **연 240만원은 금방 채워집니다.** 2교대 생산직이면 몇 달 만에 한도를 넘길 수 있습니다. 한도를 넘긴 뒤에도 계속 비과세로 처리하면 세금을 덜 걷은 것이 되어 나중에 추징 대상이 됩니다. 반대로 처음부터 과세로 처리하면 직원이 받을 수 있는 혜택을 못 받습니다.

## 결정할 것

- [ ] **"생산직"을 어떻게 판정할까요?** 지금 직군 구분이 사무직/생산직/연구직으로 되어 있는데, 이 값을 그대로 쓸까요? (법상 생산직 범위와 사내 직군 구분이 다를 수 있음)
- [ ] **월정액급여에 무엇을 포함할까요?** 특히 **식대**를 포함할지 (포함하면 210만원 기준을 넘기는 사람이 늘어남)
- [ ] **대상자 판정을 언제 할까요?**
  - 연 1회 (연초에 정하고 1년간 유지) → 관리 쉬움
  - 매월 (월정액급여가 매달 변하므로) → 정확하지만 복잡
- [ ] **연 240만원 누계를 어떻게 관리할까요?** 직원별로 올해 얼마나 썼는지 누적하고, 한도를 넘으면 그 달부터 과세로 자동 전환
- [ ] 매년 초 **대상자 재판정** 절차를 어떻게 둘까요? (작년 총급여가 확정된 뒤에 판정 가능)

## 확정되면 달라지는 것

- 소득세·지방소득세 계산
- 4대보험료 계산 기준 금액
- 급여명세서의 과세/비과세 구분 표기
- 연말정산

# 안건 3. 최저임금 검증

## 한 줄 요약

**최저임금보다 적게 주면 법 위반인데, 시스템에 미달 여부를 확인하는 절차가 없습니다.**

## 지금 상태

| | 내용 |
|---|---|
| **정책서** | 최저임금 언급 없음. "일용직 시급은 최저임금 변경에 따라 바뀔 수 있다"는 문장만 있음 |
| **시스템** | 검증 기능 없음 |

**왜 정규직도 검증이 필요한가**
정규직은 월급을 받으니 최저임금과 무관해 보이지만, **월급을 시간당으로 나눈 금액(통상시급)** 이 최저임금보다 낮으면 위반입니다. 특히 근무시간이 긴 근무조(9시간~10시간 30분조)나 저연차 직원에서 발생할 수 있습니다.

## 결정할 것

- [ ] **최저임금에 무엇을 포함해서 계산할까요? (산입범위)** — 현재 법은 상여금·복리후생비를 전액 포함합니다. **식대·직무수당을 포함하는지에 따라 미달 여부가 바뀝니다.** 이게 가장 중요한 결정입니다
- [ ] **언제 검증할까요?**
  - 임금계약을 쓸 때 (사전 차단)
  - 급여 정산할 때 (사후 확인)
  - 최저임금이 새로 고시될 때 전 직원 일괄 재검증
  - → 3개 다 하는 게 안전합니다
- [ ] **미달이면 어떻게 할까요?** 저장 자체를 막을까요(차단), 경고만 띄우고 진행시킬까요?
- [ ] **검증 대상** — 일용직 시급 + 정규직·계약직 통상시급 양쪽 다 볼까요?
- [ ] 수습자는 감액하지 않으므로 **별도 기준 없음** (확정)

## 확정되면 달라지는 것

- 임금계약 작성 단계
- 급여 정산 전 검증 단계
- 매년 1월 최저임금 갱신 작업

# 안건 4. 산재 병가 처리

## 한 줄 요약

**업무 중 다쳐서 쉬는 기간을 "결근"으로 처리하고 있는데, 결근으로 보면 안 됩니다.** 연차·주휴·퇴직금이 전부 틀어집니다.

## 지금 상태

**병가(산재) 코드는 3곳에 있습니다.**

| 구분 | 코드 | 경로 |
|---|---|---|
| 일반근태 | ATTC01 | 조퇴 → 병가(산재) |
| 일반근태 | ATTD01 | 외출 → 병가(산재) |
| 휴가 | HOLG02 | 보건 → 병가(산재) |

무급 병가는 각각 ATTC02 / ATTD02 / HOLG03 = 병가(무급) 입니다.

### 문제 3가지

**① 산재를 "결근"으로 표기합니다**
주간 근태표에서 산재(HOLG02)와 무급병가(HOLG03)를 **둘 다 결근으로 처리**합니다. 산재를 결근으로 보면:

| 영향 | 내용 |
|---|---|
| 연차 | 산재로 쉰 기간은 **출근한 것으로 봐야** 합니다(법). 결근 처리하면 연차가 덜 생깁니다 |
| 주휴수당 | 결근이 있으면 주휴를 안 주는데, 산재는 결근이 아니므로 주휴를 줘야 합니다 |
| 퇴직금 | 산재 기간은 평균임금 계산에서 **빼야** 합니다. 결근으로 두면 평균임금이 낮아져 퇴직금이 줄어듭니다 |
| 근속 | 산재 기간도 근속기간에 **포함**됩니다 |

**② 장기 요양을 담을 코드가 없습니다**
산재는 몇 주~몇 달 쉬는 경우가 많은데, 현재는 **조퇴 / 외출 / 하루 단위 보건휴가** 3가지만 있습니다. 휴직 종류도 육아휴직(본인)·육아휴직(배우자)·가족돌봄휴직 3개뿐이라 **산재 요양휴직이 없습니다.**

**③ 정책서에 "산재"라는 단어가 한 번도 안 나옵니다**
코드만 있고 규정이 없는 상태입니다.

### 참고 — 산재 시 돈은 누가 주는가

| 기간 | 지급 주체 | 금액 |
|---|---|---|
| 요양 시작 후 **3일 이내** | **회사** | 평균임금의 60% (공단이 안 주는 구간) |
| 요양 **4일 이상** | 근로복지공단 | 평균임금의 70% (회사는 무급) |
| 나머지 30% | — | **회사가 보전할지는 우리가 정할 일** |

# 안건 5. 주 52시간 초과분 → 상여금2 지급

## 한 줄 요약

**주 52시간을 넘긴 근무는 상여금2로 지급하기로 정했는데, 계산 방법과 판정 기준이 없습니다.**

## 지금 상태

| | 내용 |
|---|---|
| **정책서** | 지급항목 정의에 `상여금2 = 주 52시간 초과근무 발생 시 지급하는 시간외수당`, 입력방식 `자동`, 근태 연동 — **여기까지는 있음** |
| **없는 것** | 52시간을 어떻게 세는지, 금액을 어떻게 계산하는지, 연장수당과 겹치는지 |
| **시스템** | 52시간 계산 로직 자체가 없고, 상여금2는 손으로 입력하는 항목으로 되어 있음 |

## ⚠️ 먼저 짚어야 할 것

**52시간을 넘겨 일한 것 자체는 수당을 줘도 법 위반이 해소되지 않습니다.** (근로기준법 §53 위반, 형사처벌 대상)

상여금2는 "이미 넘긴 근무를 어떻게 지급 처리할 것인가"의 방법이고, **넘기지 않게 막는 절차는 별개로 필요합니다.**

그래서 먼저 정할 것은 **"상여금2를 왜 별도 항목으로 두는가"** 입니다.

- **(가) 급여대장 표기를 분리하려는 목적** — 연장수당으로 찍으면 52시간 초과 근무 사실이 기록으로 남으므로, 항목을 나눠서 관리하려는 실무적 이유
- **(나) 진짜 별도로 더 주는 수당** — 연장수당은 그대로 주고 추가 지급

**(가)인지 (나)인지에 따라 계산식이 완전히 달라집니다.** 이걸 정하지 않으면 뒤 질문에 답할 수 없습니다.

## 결정할 것

- [ ] **상여금2의 목적이 (가)인가요, (나)인가요?** ← 가장 먼저
- [ ] **52시간을 어떤 단위로 셀까요?** 주 단위인가요, 월로 환산할까요? 탄력근로제·선택근로제를 도입할 계획이 있나요?
- [ ] **52시간에 무엇을 포함할까요?** 소정근로 40시간 + 연장 12시간 기준인가요? **휴일근무도 포함**하나요?
- [ ] **연장수당과의 관계** — 52시간 초과분을 연장근무수당에서 **빼서** 상여금2로 옮기나요, 아니면 연장수당은 그대로 두고 상여금2를 **추가**하나요? (= 이중 지급 여부)
- [ ] **금액 계산** — 통상시급 × 1.5배를 그대로 쓸까요?
- [ ] **세금·통상임금·퇴직금** — 상여금2는 과세인가요? 통상임금에 넣나요? 퇴직금 평균임금에 넣나요?
- [ ] **사전 차단** — 초과근무를 신청할 때 52시간에 가까워지면 경고를 띄우거나 신청을 막을까요?
- [ ] **특별연장근로 인가** 절차를 정책에 넣을까요?

## 확정되면 달라지는 것

- 지급항목 상여금2의 계산 방식
- 근태의 주간 근로시간 집계
- 초과근무 신청 단계의 경고·차단
- 급여명세서 표기

# 안건 6. 식권(바우처)

## 한 줄 요약

| | 정책서 v1.5 | 식권 정산 화면 |
|---|---|---|
| **지급 기준** | 초과근무 신청할 때 "식대" 체크 → 인사담당자 승인 → 식권 지급 | 근무스케줄 기준 자동 집계 (하루 8시간 → 1장, 10시간 이상 → 2장) |
| **금액** | 10,000원 | 10,000원 × 식수 |
| **지급 시점** | 승인 후 | **전월 말에 미리 지급(선지급)** |
| **급여 연동** | **"ERP에서는 지급하지 않는다"** | **미사용분을 다음 달 급여에서 차감** |

→ **같은 회사에 두 가지 식권 제도가 병존하는 상태**입니다. 이걸 먼저 정리해야 나머지 질문에 답할 수 있습니다.

## 결정할 것

### 먼저

- [ ] **어느 정책이 현행인가요?** 초과근무 기반인가요, 근무스케줄 기반 선지급인가요? 아니면 둘 다 운영하나요?

### 그다음 (급여 영향)

- [ ] **식권이 세금 대상인가요?** 실제 식사를 제공하는 형태면 **비과세**, 현금처럼 쓸 수 있으면 **과세**입니다. 식권대장이 어느 쪽인지 확인이 필요합니다
- [ ] **식대 비과세 월 20만원 한도와 겹치나요?** 급여에 식대 항목이 따로 있으면 합산해서 20만원까지만 비과세입니다
- [ ] **선지급분을 급여에서 차감한다면**, 공제 항목을 새로 만들까요? (지금은 "기타공제"에 손으로 넣어야 함)
- [ ] **식권을 통상임금에 넣나요?** (넣으면 연장·야간수당이 올라갑니다)
- [ ] 선지급 후 회수하는 구조이므로, **가불·선지급금 회수 규칙을 일반화**해둘까요? 그러면 식권도 특별 취급이 아니게 됩니다

### 범위 확인

지금 시스템에 실체가 있는 건 **식권뿐**입니다. 아래는 도입 계획이 있으면 함께 논의합니다.

| 종류 | 현황 | 급여 쟁점 |
|---|---|---|
| 식권 (식권대장) | 화면 있음 | 위 항목들 |
| 복지포인트 | 없음 | 통상임금에는 안 들어가지만 **세금은 냅니다** |
| 명절 선물·기프트카드 | 없음 | 과세 대상, 지급명세서 반영 필요 |

- [ ] **복지포인트·명절 선물도 이번에 함께 다룰까요?**

## 확정되면 달라지는 것

- 지급항목(식대) 및 공제항목(식권 차감)
